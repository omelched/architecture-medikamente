# Задание 4

| Проблемное место                                                             | Категория  | Рекомендации                                                                                                                                                          | Критичность |
| ---------------------------------------------------------------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| Нет компетенций в фуллстек-разработке                                        | Люди       | Нанять выделенного фронтенд-разработчика, выделенного бэканд-разработчика                                                                                             | Высокая     |
| Минимальный IT-штат                                                          | Люди       | Расширить IT-штат или привлечь силы интеграторов                                                                                                                      | Высокая     |
| Vendor-locking в 1С                                                          | Технологии | Приступать к разбивке 1С в последнюю очередь, или оставить 1С как есть, но реализовать интеграции                                                                     | Низкая      |
| Учет в "эксельке"                                                            | Процессы   | Потребует масштабного пересмотра (цифровизации) всех процессов, с переобучением персонала                                                                             | Высокая     |
| Отсутствие опыта использования cloud-native технологий                       | Окружение  | Отсутствие примеров использования стека потребует проработки CI/CD процессов, настройки observability с нуля                                                          | Высокая     |
| Переход из ФС в клауд                                                        | Окружение  | Перенос данных из файловой системы в клауд (например в S3 хранилище) потребует идемпотентной миграции, с возможностью отката и выполнения ее заново (в случае ошибок) | Средняя     |
| Миграция больших объёмов данных без стратегии поэтапного переноса            | Процессы   | Разработать поэтапный план миграции (cutover), использовать временное двустороннее реплицирование, предусмотреть откат и dry-run миграции                             | Высокая     |
| Отсутстивие отказоустойчивости, катастрофойустойчивости новой инфраструктуры | Окружение  | Создать отказоустойчивый кластер, обеспечить резервирование на уровне сети, вычислений и хранилища, перенести критичные сервисы в облако или на кластер               | Высокая     |
| "Битые ссылки" между Excel, 1С и файлами                                     | Процессы   | Предусмотреть ACL-сервисы, вычищающие и исправляющие данные, альтернатива - ETL хранилище                                                                             | Высокая     |
| Отсутствие системы наблюдаемости                                             | Технологии | Ввести Observability-стек (Prometheus + Grafana, Victoria Metrics, ELK), включить мониторинг SLA                                                                      | Средняя     |
