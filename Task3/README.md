# Задание 3

## Классификация данных

| Категория данных                  | Подкатегории                                                           | Состояние                       | Уровень чувствительности | Уровень риска | Обоснование                                                    |
| --------------------------------- | ---------------------------------------------------------------------- | ------------------------------- | ------------------------ | ------------- | -------------------------------------------------------------- |
| Персональные данные (ПД)          | ФИО, телефон, email                                                    | Хранение / передача / обработка | Средний                  | Средний       | Требования 152-ФЗ, риск утечки контактов                       |
| -//-                              | Паспортные данные, адрес регистрации                                   | Хранение / передача             | Высокий                  | Высокий       | Идентифицирующие данные, риск мошенничества                    |
| Медицинские данные (обезличенные) | Результаты анализов без привязки к личности                            | Хранение / передача / обработка | Высокий                  | Средний       | Медицинская тайна, потенциальный вред в случае утечки          |
| Медицинские данные + ПД (связка)  | История болезни, анализы, диагнозы, привязанные к конкретному пациенту | Хранение / передача / обработка | Максимальный             | Максимальный  | Наиболее критичные данные по 152-ФЗ (специальная категория ПД) |
| Административные данные           | Расписание врачей, графики, записи                                     | Хранение / передача             | Низкий                   | Средний       | Риск для бизнес-процессов (операционные сбои)                  |
| Финансовые данные                 | Платежи, отчёты, бухгалтерия                                           | Хранение / передача             | Высокий                  | Высокий       | Коммерческая тайна, риск штрафов при нарушении учёта           |
| ТМЦ и складские данные            | Остатки, закупки                                                       | Хранение / обработка            | Средний                  | Низкий        | Влияние на операционные процессы, низкая конфиденциальность    |
| Технические журналы, логи         | Аудит доступов, системные логи                                         | Хранение / передача             | Средний                  | Высокий       | Могут раскрывать конфиденциальную инфу и действия сотрудников  |

## Инструменты защиты

| Категория                            | В покое (storage)                            | При передаче | При обработке                             | Автоматизированный контроль     |
| ------------------------------------ | -------------------------------------------- | ------------ | ----------------------------------------- | ------------------------------- |
| ПД                                   | AES-256, шифрование БД, сегментация          | TLS          | RBAC/ABAC, журналирование                 | DLP, тегирование (BigID), SIEM  |
| ПД (представление в других сервисах) | Токенизация                                  | TLS          | RBAC/ABAC, журналирование                 | DLP, SIEM                       |
| Медданные (обезличенные)             | AES-256, отдельное хранилище                 | TLS          | RBAC/ABAC                                 | SIEM                            |
| Медданные + ПД (история болезни)     | AES-256, токенизация идентифицирующих данных | TLS          | RBAC/ABAC                                 | DLP, DAM, анти-утечные политики |
| Расписание врачей                    | Репликация, бэкапы                           | TLS          | RBAC/ABAC                                 | SIEM (низкий приоритет)         |
| Финансовые данные                    | Возможности шифрования 1С                    | TLS          | Ролевые модели, дуальное подтверждение    | DLP, SIEM, журналы 1С           |
| Логи и аудит                         | Маскировка идентифицирующих данных           | TLS          | Защита от изменения - нельзя удалить логи | SIEM                            |
