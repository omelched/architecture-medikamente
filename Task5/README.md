# Задание 5

## Выбор стратегии

В связи с тем, что:

- в компании крайне небольшой IT-штат (3 человека)
- используются устаревшие процессы (Excel, файловый режим 1С)
- отсутствует централизованная архитектура
- отсутствуют DevOps-практики, наблюдаемость, CI/CD
- есть необходимость масштабирования в виду открытия филиалов
- есть неизбежность цифровой трансформации бизнес-процессов.

Предлагается использование High-level design, поскольку необходимо спроектировать архитектуру с нуля, реализовать цифровую трансформацию бизнес-процессов.
Параллельно с проведением архитектурных изысканий, потребуется расширить IT-штат, набрав недостающих специалистов.

Минусы Parallel run для текущего сценария:

- сложность двухсторонней синхронизации для неразмеченных данных (Excel, JPG, PDF...)
- удвоенная нагрузка на маленький IT-штат (поддерживать обе системы)
- не подходит при миграции с файловых хранилищ на доменно-ориентированную архитектуру.

Минусы Branch by Abstraction для текущего сценария:

- невозможно выделить абстракции, потому что нет существующей системы в обработке данных
- при реализации абстракции, потребуется реализовать интеграции с 1C, экселем и файловым хранилизем
