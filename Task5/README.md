# Задание 5

## Выбор стратегии

В связи с тем, что:

- компания не имеет серьезного IT-штата
- методы хранения данных и сопровождения текущих бизнес-процессов фатально устаревшие

Предлагается использование High-level design. Параллельно с проведением архитектурных изысканий, потребуется расширить IT-штат, набрав недостающих специалистов.
